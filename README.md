# CGPA Prediction & Academic Optimization

A machine learning project that predicts students' CGPA using academic performance and study habits.

## Technologies
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook, Streamlit

## Model
- Algorithm: Linear Regression
- Preprocessing: StandardScaler
- Evaluation: Mean Absolute Error (MAE) and Mean Squared Error (MSE)

## Input Features
Previous CGPA, total units, average CA score, higher-unit courses, test preparation, assignment attitude, procrastination, study hours, attendance, extracurricular hours, and access to past questions.

This project is for educational purposes. Predictions are estimates, not guaranteed academic outcomes. Protect student information and do not publish personal or identifiable survey data.
